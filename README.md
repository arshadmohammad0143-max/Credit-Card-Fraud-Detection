# 💳 Credit Card Fraud Detection System

## 📌 Project Overview

This project is a Machine Learning based Credit Card Fraud Detection System developed using Python and Flask.

The system predicts whether a credit card transaction is:

- ✅ Normal Transaction
- 🚨 Fraud Transaction

The application uses a trained Logistic Regression model and provides a web interface for checking transactions.

## 🛠️ Technologies Used

- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- Logistic Regression
- StandardScaler
- Joblib
- HTML
- CSS
- JavaScript
